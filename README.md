# 3dlife-manager
Менеджер сетей для 3D-принтера

## Установка на Raspberry Pi

На принтере должен работать NetworkManager. Соберите интерфейс из текущей версии репозитория с помощью Node.js 22 и npm.

```sh
cd frontend
npm ci
npm run build
cd ..
sudo bash instal.sh
```

Интерфейс доступен на порту 3000. Ограничьте доступ к нему доверенной управляющей сетью. API позволяет менять сетевые настройки принтера и доступен без входа.

Для локальной разработки Vite проксирует запросы `/wifi/` на backend по адресу `127.0.0.1:5000`.
