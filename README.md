# 3dlife-manager

Менеджер сетей для 3D-принтера.

## Установка на Raspberry Pi

На принтере должен работать NetworkManager. Скачайте архив `3dlife-manager-<версия>.tar.gz` из GitHub Releases, распакуйте его и запустите установщик. Например, для версии `v0.1.0`:

```sh
tar -xzf 3dlife-manager-v0.1.0.tar.gz
cd 3dlife-manager-v0.1.0
sudo bash instal.sh
```

Архив содержит готовый фронтенд. Node.js и npm на принтере не нужны. Установщику нужен доступ к репозиториям APT и Python для установки зависимостей backend.

Если принтер уже настроен как точка доступа через `3dlifeartpro_config/create-ap.sh`, сначала запустите обновлённый скрипт `sudo bash create-ap.sh --fix-lifecycle`. Это отключит старый dispatcher, который останавливал точку доступа при отключении клиентского Wi-Fi или Ethernet.

Интерфейс доступен на порту 3000. Ограничьте доступ к нему доверенной управляющей сетью. API позволяет менять сетевые настройки принтера и доступен без входа.

## Сборка релиза

На компьютере с Node.js 22 и npm выполните из корня репозитория:

```sh
npm --prefix frontend ci
bash package-release.sh v0.1.0 /tmp/3dlife-releases
```

Приложите полученный `3dlife-manager-v0.1.0.tar.gz` к релизу на GitHub с тем же тегом.

Для локальной разработки Vite проксирует запросы `/wifi/` на backend по адресу `127.0.0.1:5000`.
